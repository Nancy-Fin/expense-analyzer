# Expense Analyzer

A beginner Python project that reads a file of transactions and summarizes spending by category.

## Why I'm building this

I have a background in finance and accounting, where I worked with transactions, reports, and Excel every day. I'm learning Python to automate the kind of work I used to do by hand.

## What it will do

- Read a CSV file of sample transactions (dummy data only, no real financial information)
- Group spending by category
- Print a monthly summary

In progress. I just started this project and will update it as I build.
