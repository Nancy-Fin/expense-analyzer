# Expense Analyzer

A beginner Python project that reads a file of transactions and summarizes spending by category.

## Why I'm building this

I have a background in finance and accounting, where I worked with transactions, reports, and Excel every day. I'm learning Python to automate the kind of work I used to do by hand.

## What it does

- Reads a CSV file of sample transactions (dummy data only, no real financial information)
- Adds up spending by category
- Prints a summary

## How to run it

1. Make sure Python 3 is installed
2. Download this repository
3. Run this command in the project folder:

```
python3 analyzer.py
```

## Sample output

```
Spending by category
--------------------
Groceries: 146.20
Transport: 19.50
Utilities: 133.00
Eating Out: 64.15
Entertainment: 18.00
```
